操作方法：左から「バトル」「貢献者」「ピンク」の3枠。BGMはそれぞれ独立して再生でき、重ねて鳴らせます。押した枠だけ停止できます。音量も枠ごとに調整可能。バトルは裏側で①と②を曲末に自動MIXします。
再生バー：各枠のシークバーを動かして再生位置を変更できます。バトルの現在再生中の①/②も表示します。
キー：Q＝バトル、W＝貢献者、E＝ピンク、1＝歓声と拍手、2＝メンレベアップ、3＝ちゃんちゃん、4＝出題、5＝正解、6＝不正解、7＝小パンチ、Esc＝すべて停止。
音源変更：バトル枠の「①/②の音源を変更」から差し替え、その他は歯車から変更できます。
保存と配信音声について
音源の追加・差し替えはIndexedDBに保存します。ブラウザのサイトデータ削除で消える場合があるため、バックアップを保存してください。バトル1・2、ピンク、貢献者、効果音はユーザー提供音源をZIPに収録。貢献者は冒頭180秒に編集済み、バトルラストは削除済みです。配信での音源利用可否は各権利者・配信サービスの規定をご確認ください。OBS等への取り込みは配信前にテストしてください。複数BGMの同時再生は音が大きくなりやすいので音量を低めに設定してください。
