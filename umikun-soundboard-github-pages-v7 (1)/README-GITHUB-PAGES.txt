UMI SOUND DESK v7 — GitHub Pages 配置用

1. GitHubで新しいリポジトリ（例: umi-sound-desk）を作成
2. このZIPを解凍し、index.html と audio フォルダをリポジトリのルートへアップロード
3. Settings → Pages → Build and deployment → Deploy from a branch
4. Branch: main / Folder: /(root) を選択して Save
5. https://USERNAME.github.io/umi-sound-desk/ で開く（USERNAMEは自分のアカウント名）

注意：公開リポジトリでは音声ファイルを他の人が取得できます。公開・配信する音源の権利を必ず確認してください。
「ヨッシー」等の第三者作品に由来する音声は、許諾がない場合は公開しないでください。
GitHub Pagesは個人利用の静的サイト向けで、商用SaaSの運用には使用できません。
BGM音声が配信視聴者に聞こえるかはOBS等の設定に依存します。
